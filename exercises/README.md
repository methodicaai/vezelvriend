# Oefeningen

De oefeningen voor deelnemers. Elke oefening heeft een doel, een opdracht, een voorbeeldprompt zonder context, een voorbeeldprompt met context en een reflectievraag.

Antwoorden staan hier bewust niet: die bespreek je met de trainer.

In de voorbeeldprompts staat tussen `{{ }}` wat je zelf moet invullen. Op de site worden dat invulvakken met een knop om de hele prompt te kopiëren.
